### Publicar cambios
GitHub Pages es un hosting estático. El panel puede editar y guardar una copia local en el navegador, pero no puede escribir directamente en GitHub.

Para publicar:
1. Entra a `admin.html`.
2. Edita lo que quieras.
3. Pulsa **Exportar config.js**.
4. Sustituye el `config.js` de tu repositorio por el archivo descargado.
5. GitHub Pages actualizará el portafolio.
